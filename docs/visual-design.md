# Agent World 视觉层设计方案

## 核心概念：蓝图风格的六边形城市经营

每个项目是一片**六边形网格城区**，任务堆叠成**建筑**，整体呈现蓝图线框美学。

---

## 一、六边形网格系统

### 网格类型
每个项目拥有一组相连的六边形网格，每个网格代表一个**任务类别**：

| 网格标签 | 图标 | 说明 |
|---------|------|------|
| 调研分析 | 🔬 | research, analysis |
| 前端开发 | 🖥️ | frontend, UI |
| 后端开发 | ⚙️ | backend, API |
| 设计 | 🎨 | design, UX |
| 文档 | 📝 | docs, specs |
| 测试 | 🧪 | testing, QA |
| 安全 | 🔒 | security |
| 运维 | 🚀 | devops, deploy |
| 运营 | 📢 | marketing, content |

### 网格布局
- 项目网格呈**蜂巢状**排列，中央为项目总览塔
- 网格数量根据项目实际任务类别动态生成（无任务的类别不显示网格）
- 每个网格底部显示类别标签（等宽字体，蓝图风格）

### 连接网格（项目间）
- 不同项目之间通过**桥接网格**连接
- 有关联的项目：桥接网格颜色 = 两个项目颜色的渐变混合
- 无关联的项目：桥接网格为灰色（#444）
- 桥接网格上可显示关联类型标签（如"共享API"、"依赖"等）

## 二、建筑系统

### 任务 → 建筑层
每个网格上的任务堆叠成建筑，**一个任务 = 一层楼**。

### 建筑风格（按网格类别）
| 类别 | 建筑风格 | 说明 |
|------|---------|------|
| 调研分析 | 天文台/圆顶 | 顶部半球形 |
| 前端开发 | 玻璃幕墙塔 | 透明层叠 |
| 后端开发 | 工业烟囱塔 | 粗壮方正 |
| 设计 | 螺旋塔 | 扭转上升 |
| 文档 | 图书馆塔 | 层层书架 |
| 测试 | 实验室塔 | 管道缠绕 |
| 安全 | 堡垒塔 | 厚重城墙 |
| 运维 | 信号塔 | 天线顶部 |
| 运营 | 广播塔 | 喇叭造型 |

### 中央塔（项目总览）
- 位于项目网格群的**正中央**
- 高度 = 最高建筑 + 1 层
- 风格：综合体/地标建筑
- 点击展示项目总览信息（名称、状态、进度、团队）

### 任务状态 → 楼层效果
| 状态 | 视觉效果 |
|------|---------|
| todo | 线框/虚线轮廓（半透明，待建设） |
| doing | 实线 + 脉冲发光动画（施工中） |
| review | 实线 + 黄色闪烁（审查中） |
| done | 实线填充 + 微光（已完工） |

## 四、交互设计

### Hover 效果
- **网格 hover**：网格边框高亮 + 浮出类别标签 + 显示任务数量气泡
- **建筑 hover**：该层楼高亮 + 浮出任务标题卡片
- **中央塔 hover**：项目名称 + 进度条浮出

### 点击交互
- **网格点击**：展开该类别的任务列表面板（侧边栏）
- **建筑层点击**：展示任务详情（标题、状态、负责人、描述）
- **中央塔点击**：展示项目总览面板（所有类别统计、团队、时间线）

### 视角控制
- OrbitControls：拖拽旋转、滚轮缩放
- 双击建筑：镜头飞入聚焦
- ESC：返回全局视角

## 五、动态效果

### Agent 活动
- Agent 以发光光点形式在城市中移动
- 当 agent 操作某个任务时，光点飞向对应建筑
- 留下渐隐的轨迹线

### 实时更新（Supabase Realtime）
- 新任务创建：建筑"生长"一层（向上动画）
- 任务完成：该层从线框变为实体（填充动画）
- 新项目创建：新的六边形网格群从地面"升起"

### 后处理
- Bloom：建筑发光边缘
- 网格扫描线：缓慢移动的水平扫描线（蓝图感）

## 六、数据映射

### 数据库 → 视觉元素
```
projects → 六边形网格群（颜色、位置）
tasks.tags/类别 → 网格位置
tasks → 建筑层（高度、状态效果）
tasks.status → 楼层渲染风格
tasks.priority → 楼层高度权重（高优先级在底层，更稳固）
agents → 移动光点
activities → 粒子轨迹
```

### 任务类别推断
任务需要一个 `category` 字段（或从 tags 推断）映射到网格：
- 含 "调研/research/分析" → 调研分析
- 含 "前端/frontend/UI/组件" → 前端开发
- 含 "后端/backend/API/数据库" → 后端开发
- 含 "设计/design/UX" → 设计
- 含 "文档/doc/spec" → 文档
- 含 "测试/test/QA" → 测试
- 含 "安全/security" → 安全
- 含 "部署/deploy/CI" → 运维
- 含 "运营/内容/blog" → 运营
- 默认 → 最近的空闲网格

## 七、技术实现要点

- **六边形网格**：自定义 `HexagonGeometry`（flat-top），用 `InstancedMesh` 批量渲染
- **建筑**：`ExtrudeGeometry` 从六边形底面向上拉伸，每层独立 mesh
- **蓝图线框**：`EdgesGeometry` + `LineSegments`，不用面填充
- **文字标签**：drei `<Text>` 或 `<Html>` 组件
- **后处理**：`@react-three/postprocessing` 的 Bloom + ScanlineEffect
- **状态管理**：Zustand store，Supabase Realtime 订阅更新
- **响应式**：移动端降级为 2D 六边形网格（Canvas 2D 或 SVG）
