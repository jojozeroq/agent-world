## 一、核心风格：技术蓝图 / 工程图纸美学

**不是深色科技感，是浅色工程蓝图风格！**

- 浅灰色网格点阵背景（dot grid），类似工程制图纸
- 细线框结构，精确感
- 单色灰度系（黑白灰），无彩色干扰
- 等宽字体全程使用，技术文档感
- 几乎无圆角，保持锐利

### 色彩系统
```
#000000 — 黑（主文字、线框）
#333333 — 深灰（次要文字）
#CCCCCC — 浅灰（边框、分隔线）
#FFFFFF — 白（背景区域）
背景：浅灰 + 网格点阵
```

## 三、关键设计元素

### 顶部导航
- 等宽字体，全大写
- 细边框矩形按钮
- 极简，无装饰

### 数据面板格式
```
▶ SECTION TITLE
LABEL: VALUE    LABEL: VALUE
```
- ▶ 小三角形折叠指示器
- 等宽字体对齐数值
- 十六进制显示 (0x00000000)
- 紧凑间距 8px/16px

### 数据可视化
- 进度条表示内存/VRAM占用
- 状态标签 ON/OFF, IDLE/RUNNING
- 色条显示调色板
- 缩进和分割线区分层级

### 中央展示区
- 设备线框图（透明，仅轮廓）
- 屏幕区域纯黑矩形
- 底部操作按钮

## 四、映射到 Agent World

| GBA 模拟器 | Agent World |
|-----------|-------------|
| CPU 寄存器 | Agent 状态（名称、角色、当前任务） |
| FLAGS 标志位 | Agent 在线/空闲/离线状态 |
| DISPLAY CTRL | 项目统计（任务数、完成率） |
| BG CONTROL | 各 Agent 负载/进度条 |
| PALETTE 色条 | Agent 主题色标识 |
| GBA 线框图 | Agent 协作网络线框图（中央） |
| 屏幕区域 | 当前选中 Agent 的详情/活动 |
| MEMORY MAP | 知识库容量/使用率 |
| DMA CHANNELS | 任务队列状态 |
| TIMERS | Agent 活跃时间/最后活动 |
| INTERRUPTS | 最近事件/通知 |

## 五、设计原则

1. **单一模式** — 只保留蓝图风格，不做模式切换
2. **灰度为主** — 黑白灰，Agent 主题色仅作为微小点缀
3. **等宽字体** — 全程 monospace，营造技术感
4. **线框优先** — 中央 3D 场景用线框渲染，不用实体填充
5. **数据驱动** — 进度条、状态标签、数值对齐
6. **网格背景** — dot grid 是标志性特征
7. **无圆角** — 锐利边角，1px 边框
8. **紧凑排版** — 8px/16px 间距基准
