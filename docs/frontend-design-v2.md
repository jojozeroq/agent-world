# Agent World 前端设计方案 v2

> 参考：GBA 模拟器界面风格
> 日期：2026-02-20
> 状态：设计稿

## 核心概念

把 Agent World 想象成一台 **"AI 协作设备"**：
- GBA 模拟器有硬件外壳 → Agent World 有"控制台"外框
- GBA 中间是游戏屏幕 → Agent World 中间是主视图区（3D世界/任务看板/知识库等）
- GBA 左右显示硬件信息 → Agent World 左右显示系统状态

## 三栏详细设计

### 左侧面板 — 系统状态（类比 GBA 左侧硬件信息）

显示"设备"运行状态，让用户一眼看到整个系统的健康度。

- **Agent 列表**：5个 agent 的头像/emoji + 名称 + 在线状态指示灯
  - 🟢 在线（30分钟内活跃）
  - 🟡 空闲（30分钟-2小时）
  - ⚫ 离线（>2小时）
- **系统统计**
  - 今日完成任务数
  - 活跃项目数
  - 知识条目总数
  - 最近活动时间
- **点击 Agent → 右侧面板显示该 Agent 详情，中央视图聚焦该 Agent**

### 中央主视图 — 交互内容区（类比 GBA 游戏屏幕）

这是核心区域，根据底部导航切换不同内容：

| 视图 | 内容 | 交互 |
|------|------|------|
| 🌐 世界 | 3D/2D Agent 协作场景，节点+连线 | 旋转、缩放、点击节点 |
| 📋 任务 | 看板视图（待办/进行中/完成） | 拖拽、筛选、按 Agent 过滤 |
| 📚 知识 | 知识条目列表/卡片 | 搜索、分类浏览 |
| 📊 项目 | 项目概览、进度条、里程碑 | 展开详情 |

- 默认显示 🌐 世界视图（3D Agent 场景）
- 切换视图时有平滑过渡动画
- 中央区域占据最大空间，是视觉焦点

### 右侧面板 — 详情/动态（类比 GBA 右侧硬件信息）

上下文相关的详细信息，随左侧/中央的选择而变化：

- **默认状态**：显示全局活动流（最近的 agent 动态）
- **选中 Agent 时**：
  - Agent 角色描述
  - 当前正在做的任务
  - 最近活动列表（时间线）
  - 负责的任务统计
- **选中任务时**：任务详情、负责人、进度、关联知识
- **选中知识时**：知识条目全文、来源、关联 agent

## 双艺术风格

### 简笔画模式（Sketch）
- 背景：#FAFAFA 浅灰白
- 边框/线条：手绘感虚线，#333 深灰
- 面板分隔：细线条
- Agent 节点：线条圆形 + 主题色描边
- 整体感觉：纸上草图、极简

### 色彩模式（Color）
- 背景：柔和渐变（深蓝→紫）
- 面板：半透明毛玻璃效果
- Agent 节点：主题色填充 + 发光效果
- 连接线：彩色渐变
- 整体感觉：科技感、温暖活泼

### 切换
- 右上角或底部栏提供切换按钮
- 切换时 CSS 变量过渡 ~0.5s
- localStorage 记住偏好

## 响应式适配

### 桌面 (>1024px)
```
[ 左侧面板 240px ] [ 中央视图 自适应 ] [ 右侧面板 280px ]
```

### 平板 (768-1024px)
```
[ 左侧面板 收起为图标栏 48px ] [ 中央视图 全屏 ]
右侧面板 → 点击后浮层弹出
```

### 手机 (<768px)
```
[ 中央视图 全屏 ]
左侧面板 → 汉堡菜单抽屉
右侧面板 → 底部上滑抽屉
底部导航栏固定
```

## 交互流程示例

1. 用户打开页面 → 看到三栏布局，中央是 3D 世界，5个 Agent 节点在运转
2. 左侧看到所有 Agent 状态，点击"陆舟" → 中央视图镜头聚焦陆舟节点，右侧显示陆舟的任务和动态
3. 底部切换到"📋任务" → 中央变为看板视图，左侧 Agent 列表不变，右侧显示任务统计
4. 点击某个任务卡片 → 右侧切换为任务详情
5. 切换艺术风格 → 整个界面平滑过渡

## 技术要点

- **框架**：Vite + React + TypeScript
- **3D**：Three.js (R3F) 用于世界视图
- **2D 视图**：纯 React 组件（任务看板、知识库、项目概览）
- **状态管理**：React Context（主题、选中状态）+ Supabase Realtime
- **样式**：CSS Variables 驱动双主题，CSS Grid 驱动三栏布局
- **部署**：纯静态输出，兼容 GitHub Pages / Deno Deploy / Vercel
